Como adicionar novos programas

Simples como editar um ficheiro JSON no GitHub

Este site lê diretamente o ficheiro programs.json na raiz do seu repositório. Para adicionar um novo software:

  1. Vá ao seu repositório no GitHub e abra o ficheiro programs.json.
  2. Clique no ícone de lápis para editar e adicione o seu bloco JSON.
